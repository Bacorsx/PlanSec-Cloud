# SC-23 · Session Authenticity

**Familia:** SC · Protección de sistemas y comunicaciones · **Capa:** Aplicación

Proteger la autenticidad de las sesiones.

- **Riesgo que mitiga:** Robo o fijación de la sesión y CSRF
- **Punto de aplicación (plantilla):** App: cookie HttpOnly/Secure/SameSite=Strict, regeneración del ID al ingresar y token CSRF en cada formulario
- **Evidencia sugerida:** curl -kI: Set-Cookie HttpOnly; Secure; SameSite=Strict
- **Prueba asociada:** P11
