# IA-2(1) · MFA para cuentas privilegiadas

**Familia:** IA · Identificación y autenticación · **Capa:** Identidad

Exigir MFA a las cuentas privilegiadas.

- **Riesgo que mitiga:** Robo o filtración de la llave SSH del administrador
- **Punto de aplicación (plantilla):** sshd + pam_google_authenticator (TOTP) para el grupo administrador
- **Evidencia sugerida:** Login pidiendo Verification code
- **Prueba asociada:** P6
