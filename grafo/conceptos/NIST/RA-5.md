# RA-5 · Vulnerability Monitoring and Scanning

**Familia:** RA · Evaluación de riesgos · **Capa:** Red

Buscar vulnerabilidades de forma periódica.

- **Riesgo que mitiga:** Vulnerabilidades conocidas sin detectar
- **Punto de aplicación (plantilla):** nmap desde el exterior (P2) y mejora con Lynis o escaneo periódico
- **Evidencia sugerida:** nmap -Pn -p 22,{PUERTO} {BD_IP}
- **Prueba asociada:** P2
