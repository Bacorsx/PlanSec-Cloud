# AC-17 · Remote Access

**Familia:** AC · Control de acceso · **Capa:** Red

Controlar y restringir el acceso remoto.

- **Riesgo que mitiga:** Acceso remoto por fuerza bruta o como root
- **Punto de aplicación (plantilla):** sshd_config: sin root, sin contraseña, AllowGroups, MaxAuthTries 3
- **Evidencia sugerida:** sshd -T filtrado; SG 22 solo desde IP admin
- **Prueba asociada:** P5
