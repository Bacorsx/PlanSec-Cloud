# AC-3 · Access Enforcement

**Familia:** AC · Control de acceso · **Capa:** Aplicación

Aplicar las autorizaciones aprobadas en cada acceso a información o funciones.

- **Riesgo que mitiga:** Usuarios que ejecutan acciones fuera de su rol
- **Punto de aplicación (plantilla):** App: roles admin / operador / auditor verificados en cada acción del servidor
- **Evidencia sugerida:** Auditor intentando registrar → «Tu rol no permite esta acción»
- **Prueba asociada:** P11
