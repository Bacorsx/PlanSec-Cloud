# README.md

# PlanSec-Cloud Generador automático de proyectos de **seguridad en infraestructura cloud sobre AWS**: con un comando crea, para cada estudiante, un repositorio listo con el sistema web de gestión del proyecto, la aplicación del caso, los instaladores para AWS y una guía paso a paso personalizada. Cada proyecto sale **distinto** (temática, diseño, motor de base de datos, firewall, zona, controles)
